# skills

Eidriahn's personal agent skills, shared across machines.

## Install

Claude Code:

```
/plugin marketplace add Eidriahn/skills
/plugin install eidriahn@eidriahn-skills
```

Codex:

```bash
codex plugin marketplace add Eidriahn/skills
codex plugin add eidriahn@eidriahn-skills
```

Both update automatically when `main` changes. Skills are invoked as `/eidriahn:<skill-name>`.

## Skills

- [pr-comment](./skills/pr-comment/SKILL.md): writes terse, outcome-first comments and review replies on your pull requests.
