# Personal Skills

Adrian's own agent skills, kept in one public repo and installed on every PC Adrian uses, in Claude Code and Codex.

## Language

**Skill**:
One folder holding a `SKILL.md` that teaches an agent one workflow.
_Avoid_: Command, prompt, recipe

**Plugin**:
The installable bundle that ships a set of Skills to an agent as one unit, updated automatically.
_Avoid_: Package, extension

**Marketplace**:
The catalogue, published from this repo, that an agent is pointed at once so it can find and update the Plugin.
_Avoid_: Registry, store
